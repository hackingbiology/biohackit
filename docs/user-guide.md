# User guide — what you can do today

Single source for the public page `/docs/user-guide` (generated by `tools/docs/export_user_guide.py`). Spec: `openspec/changes/m00c-autodev-v2/specs/dev-process/spec.md`, requirement "User guide describes only built features". Every built step cites a frontend route file that a test checks exists. Features that are planned but not built are listed separately and cite the OpenSpec requirement that specifies them. Sign-in methods follow `frontend/src/components/SignInForm.tsx` and `backend/biohackit/settings.py`.

## Steps you can take today

| step | what you do | route file |
|---|---|---|
| Open the home page | Read what biohack.it is for. From here you can start, sign in, open the ecosystem page or open the documentation. | frontend/src/app/page.tsx |
| Create your account | Choose "Get started". Sign-up and sign-in are the same page. An email code does not create a new account. A new account is created today only when you continue with the forum button, on a site that has it switched on. | frontend/src/app/(auth)/sign-up/page.tsx |
| Sign in | Choose "Sign in" and pick one of the sign-in methods below. | frontend/src/app/(auth)/sign-in/page.tsx |
| Read about sharing | If you start from "Get started" and sign in with an email code or a passkey, a welcome page opens. It explains that your profile is public by default. If you sign in with a provider button, you go to the dashboard address instead. | frontend/src/app/onboarding/page.tsx |
| See what we build on | The ecosystem page lists the open projects and open data that biohack.it reuses. | frontend/src/app/ecosystem/page.tsx |
| Import lab results from a CSV file | Open "Import lab results (CSV)" on the home page after you sign in. Choose a file and press "Check file". Each row is marked Recognised or Not recognised, with the reason. "Save report" works only when every row is recognised. After saving you can press "Undo this import". | frontend/src/app/labs/import/page.tsx |
| Type a lab report by hand | Open "Enter lab results by hand" (a link on the import page, or /labs/new) after you sign in. For each result type the LOINC code, the value exactly as your lab printed it, and the unit. Laboratory, method, device and dates are optional. Use "Add another result" for more rows. "Save report" opens the saved report. If a value is refused, the reason is shown next to that result and field, and nothing you typed is cleared. | frontend/src/app/labs/new/page.tsx |
| Look at a saved report | Open a saved report (the link after saving, or /labs/reports/<number>). Each result shows the value and unit as reported, laboratory, method, device and dates, its validation state, whether it is counted in aggregations, and a range check in words. Below the table, each result is shown against its three ranges, kept separate: the laboratory reference range, the longevity-optimal range and the safety threshold, each with its status in words and its source (shown by frontend/src/components/ResultRanges.tsx). "About this optimal range" opens the source, population, endpoint, evidence grade and last-reviewed date. A typed result looks the same as an imported one. "Undo this report" appears only for imported reports and deletes the report after you confirm; a report you typed by hand cannot be undone. | frontend/src/app/labs/reports/[id]/page.tsx |
| Read the documentation | The documentation index links to the AI surfaces map, the architecture page and this guide. | frontend/src/app/docs/page.tsx |

## Ways to sign in

| method | when it is available | source file |
|---|---|---|
| Email code | Always shown. It works only for an account that already exists. Type your email address, then type the code we send you. | frontend/src/components/SignInForm.tsx |
| Passkey | Only if your browser supports passkeys. A "Use a passkey" button then appears. It works only with a passkey you already have for this site. You cannot add a passkey on the site yet. | frontend/src/components/SignInForm.tsx |
| rapamycin.news forum account | Only on a site that has the forum connection switched on. A "Continue with rapamycin.news" button then appears. | backend/accounts/providers/discourse_connect |
