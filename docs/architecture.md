# Architecture — what exists, what is only planned

Single source for the public page `/docs/architecture` (generated by `tools/docs/export_architecture.py`). Spec: `openspec/changes/m00c-autodev-v2/specs/dev-process/spec.md`, requirement "Architecture documentation reflects the repository". Every built component cites a repository path that a test checks exists. Planned parts are listed separately and cite the OpenSpec requirement that specifies them.

## Built components

| component | layer | repo path | purpose |
|---|---|---|---|
| Django project package | backend | backend/biohackit | Settings, URL routing, WSGI and ASGI entry points for the backend |
| API URL registry | backend | backend/biohackit/api_urls.py | Collects the API routes that each app registers |
| accounts app | backend | backend/accounts | Users, profiles, social handles and sign-in endpoints |
| Discourse sign-in provider | backend | backend/accounts/providers/discourse_connect | Sign-in through a Discourse forum account |
| Demo data seeding | backend | backend/accounts/management/commands/seed_demo.py | Command that fills the staging site with demo data |
| core app | backend | backend/core | Data models for interventions, biomarkers and measurements, and the no-index middleware |
| terminology app | backend | backend/terminology | Sources, units and stored unit conversions |
| Measurement hypertable | backend | backend/core/migrations/0002_measurement_hypertable.py | Stores measurements in a TimescaleDB table split by time |
| Unit conversion service | backend | backend/terminology/services.py | Converts values with stored factors only, no AI |
| Backend tests | backend | backend/tests | Automated tests for the backend, docs pages and gates |
| Next.js app | frontend | frontend/src/app | Pages of the web app: home, sign-in, sign-up, onboarding, ecosystem and documentation |
| Documentation pages | frontend | frontend/src/app/docs | The public documentation index and its pages |
| Interface strings | frontend | frontend/src/lib/i18n.ts | All user-facing text, English first, Italian and Chinese falling back to English |
| Generated page data | frontend | frontend/src/content | JSON files generated from the Markdown sources under docs/ |
| Frontend tests | frontend | frontend/src/__tests__ | Automated tests for the web app |
| Local stack | deployment | docker-compose.yml | Database, backend and frontend containers for local development |
| Staging stack | deployment | docker-compose.staging.yml | The public staging site with demo data, one published port |
| Quality gates | process | tools/autodev2/gates.sh | The checks every change must pass before merge |
| Traceability matrix | process | tools/trace/matrix.py | Links each spec scenario to the test that declares it |
| OpenSpec validation gate | process | tools/openspec/validate_gate.py | Fails on structural errors in the specifications |
| Dependency audit gate | process | tools/audit/pip_audit_gate.py | Fails on known vulnerable backend packages |
| Licence gate | process | tools/licence/check_licences.py | Fails on licences that are not AGPL-3.0 compatible |
| Changed-file coverage gate | process | tools/coverage/changed_coverage.py | Checks test coverage of the lines a change touches |
| Static analysis gate | process | tools/semgrep/semgrep_gate.py | Scans backend and frontend code for known risky patterns |
| Strict typing gate | process | tools/mypy/mypy_gate.py | Strict type check of the apps listed for it |
| Mutation testing gate | process | tools/mutmut/mutmut_gate.py | Checks that tests catch changes in the numeric code |
| Docs exporters | process | tools/docs | Generate the documentation page data from docs/ |
